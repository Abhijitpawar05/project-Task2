# Student Performance Distribution Analysis
 Project Overview
This project focuses on statistical plots and distribution analysis to understand student performance data.
The analysis is performed using Python and Jupyter Notebook, emphasizing Exploratory Data Analysis (EDA)
through visualizations such as histograms, KDE plots, and boxplots.

# Dataset
The dataset contains records of 200 students with the following columns:

- Student_ID – Unique identifier for each student  
- Name – Student name  
- Section – Class section (A or B)  
- Study_Hours – Average daily study hours  
- Marks – Academic performance score  

 Project Objectives
- Analyze the distribution of student marks  
- Visualize data using histogram, KDE, and boxplot  
- Compare performance across different sections  
- Identify outliers, skewness, and spread  
- Provide meaningful interpretation of results  

# Visualizations Used
- Histogram of Student Marks  
- KDE Plot for distribution shape  
- Boxplot for outlier detection  
- Section-wise Boxplot comparison  

## Tools & Libraries Used
- Python  
- Pandas  
- NumPy  
- Matplotlib
